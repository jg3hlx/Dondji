# 第1章 システム操作マニュアル

ようこそ **叮咚鶏（Dondji）**。本章では電源投入後の基本操作。書き換え、校正、設定のバックアップについては第2章を参照してください。

## 1.1 基本操作

### 電源のオン／オフと音量

- ノブを回して電源をオン／オフし、回して音量を調整します。
- 本体 **`#` キー即 F キー**（短押し入る F 組み合わせキー、長押しキーロック）。

### メニューを開く

1. 短押し **MENU** 入るメニュー。
2. **↑/↓** または数文字キーすばやく移動メニュー项；もう一度押す **MENU** 入るサブ項目。
3. **EXIT** 上で位階層へ戻る、またはメニューを終する。

### 周波数モード（VFO）とチャンネルモード（MR）

| モード | 説明 |
|------|------|
| **周波数モード（VFO）** | 周波数を直接調整します。ステップ幅や変調などを変更できます |
| **チャンネルモード（MR）** | 保存する済みのメモリーチャンネルを呼び出します |

- 短押し **`3`** または **`F+3`** / 長押し **`3`**：で VFO と MR の間を切り替えます。
- **チャンネルモードでトーン、出力、周波数オフセットなどのパラメータを変更しただけでは一時のにしか有効になりません。もう一度「チャンネル保存する」を実行する必要があります。「チャンネル保存する」、チャンネル切替または再起動後も保持されます。** 详见 [1.4 チャンネルの保存する方法](#14-チャンネルの保存する方法)。
- チャンネルモードで **`F+1`**：現でのチャンネルを対応バンドのVFOへコピーし、周波数モードへ切り替えます（便于微调后再存回）。

### A／Bデュアル周波数と受信モード

- **`F+2`** / 長押し **`2`**：A／Bを切り替える（メインチャンネルモードでは無効になる場合があります）。
- 受信モード（シングル待受／デュアル待受／クロスバンドなど）はメニューで設定します；单守と双守画面例を未満に示します。

## 1.2 ラジオの開き方と使い方

叮咚鶏使用本体内蔵 **BK1080** 做FM放送、～を通じて**専用のラジオ画面**聴取（メイン画面の変調設定にあるWFMではありません）。

### 入る／終する

1. メイン画面 **`长按0`** または **`F+0`** 入るラジオ。
2. もう一度押す **`F+0`**、または短押し **EXIT**（保存する／削除の確認が表示されていない場合）終してメイン画面に戻る。

### 周波数モードとチャンネルモード（ラジオ内）

- ラジオ内短押し **`3`** または **`F+3`**：で **周波数（VFO）** と **チャンネル（MR）** の間を切り替えます。
- **周波数モード**：数文字キーを使って入力周波数、または **↑/↓** 调谐。
- **チャンネルモード**：保存する済みラジオプリセットを切り替えます。

### 国・地域のバンドを切り替える

- ラジオ画面で **短押し `1`** または **`F+1`** / **長押し `1`**：切り替える現での国／地域バンド（バンドが合わない場合は、先に切り替えてから局を検索します）。

### ラジオプリセットの保存する／削除

**周波数モードで現での周波数をプリセットリストに保存する：**

1. 周波数を合わせた後短押し **MENU**、「保存するしますか？」と表示されます。
2. 用 **↑/↓** プリセットスロットを選択。
3. もう一度押す **MENU** 保存するを確認。

**チャンネル（MR）モードで現でのプリセットを削除：**

1. 短押し **MENU**、「削除しますか？」と表示されます。
2. もう一度押す **MENU** 削除を確認。

也できます用Webサイト「写频」関連能力管理一部設定；ラジオ選択周波数/チャンネル/MR/バンド設定領域に書き込まれます（见第二章）。

### 放送局をスキャン

| 操作 | 効果 |
|------|------|
| **長押し `*`** または **`F+*`** | プリセットリストを消去して全バンドを検索（A-SCAN）、信号のある周波数をリストに保存する |
| 短押しスキャン関連操作 | 既存リストをスキャン（M-SCAN、界面有提示） |

スキャンを停止：短押し **EXIT** または **MENU**（現での状態によります）。

### その他のキー

| キー | 機能 |
|------|------|
| `F+8` | バックライト（必要に応じて） |
| `F+9` | バックライトのオン／オフ関連 |
| `F+0` | 終ラジオ |

### 注意

- 双守时：**メインチャンネル**にアマチュア無線信号が来た場合のみ、割り込みしてラジオを終します（见 FAQ）。
- ラジオBK1080を使用します；デュアル待受のポーリングとの排他仕様は第3章FAQ #12を参照してください。

## 1.3 スキャン方法

### メモリーチャンネルリストをスキャン

1. 先各チャンネルに所属するスキャンリストを設定：Webページ「写频」書き込み、またはメニュー **「チャンネル」→「チャンネル列表」**。
2. **MENU** → **「その他」→「スキャン列表」**、スキャンするリストを選択。
3. メイン画面**チャンネルモード**にする、**長押し `*`** または **`F+*`** スキャンを開始。
4. 信号のあるチャンネルを検出したら、押す **MENU** そのチャンネルで停止；信号がない場合 **MENU** / **EXIT** どちらでもスキャンを終できます。

### ワンタッチ周波数スキャンとトーンをスキャンする

1. **長押し `4`** または **`F+4`**：ワンタッチ周波数スキャン。
2. **周波数モード**で **`F+*`**：トーンスキャンを開始（CTCSS/DCS）。

結果が得られたら、できます画面の指示に従って **MENU** →「保存するしますか？」→（チャンネルモードではチャンネル番号を選択できます）→ 再 **MENU** 確認する、メモリーチャンネルに書き込みます。**EXIT** キャンセル。

### 範囲スキャンとスペクトラムへの入口

1. **デュアル待受**モードに切り替える（シングル待受では範囲スキャンを使用できません）、且“显示”中で“スペクトラム显示”選択择“简单”。
2. A、B 均切り替えるとして**周波数モード**。
3. A 開始周波数を入力、B 終周波数を入力。
4. **長押し `5`**：範囲スキャンに入る（**EXIT**を長押しして終）。
5. **`F+5`**：スペクトラム画面を開く（详见 1.6）。

### スキャン中でにチャンネルを除外

スキャンが特定のチャンネルで停止しているとき、**長押し MENU** できますそのチャンネルを現でのスキャンから除外（视ファームウェア提示）。

### 関連メニュー

| メニュー | 用途 |
|------|------|
| スキャン列表 | デフォルトリスト／すべてなどを選択 |
| 优先スキャン、優先チャンネル | 優先チャンネル |
| スキャン復元 | 信号検出後に停止／キャリア／タイムアウトなど |
| チャンネル列表 | チャンネルをスキャンリストに追加するか |

## 1.4 チャンネルの保存する方法

現での周波数とパラメータをメモリーチャンネルに書き込みます。

### 方法1：メニュー「チャンネル保存する」

1. でメイン画面周波数、トーン、出力、変調、オフセットなどを設定。
2. 短押し **MENU** → **チャンネル保存する（ChSave）** → もう一度押す **MENU**。
3. 用 **↑/↓** または入力チャンネル号、保存する先チャンネルを選択。
4. 押す **MENU** → 出现「確認する?」后もう一度押す **MENU** 完成保存する。

削除：メニュー **チャンネル削除（ChDele）**、同样必要です確認する。

也できます用Webサイト「写频」页チャンネルを一括インポート。

### 方法2：チャンネルモードで改参后必ず再存

**チャンネルモード（MR）**では、メニューでそのチャンネルのトーン、出力、帯域幅などを変更した場合：

- 変更直後は新しいパラメータで動作します；
- **「チャンネル保存する」を実行しない場合**、チャンネルを切り替えるか再起動すると変更は失われます（一時のな変更として扱われます）。

**正しい方法：** パラメータ変更後、もう一度**チャンネル保存する（ChSave）**を実行し、現でのパラメータをそのメモリーチャンネルへ書き戻します。

### 方法3：スキャン結果の保存する

ワンタッチ周波数スキャン / トーンスキャン结束后、押す界面「保存するしますか？」流程書き込みチャンネル（见 1.3）。

## 1.5 チャンネル名とピンイン入力

### 名前編集を開始

1. **MENU** → **命名チャンネル（ChName）**。
2. 有効なチャンネルを選択 → **MENU** 編集に入る。
3. 編集完後、短押し **MENU** カーソルを移動；末尾まで移動して「確認しますか？」を確認し保存する。
4. チャンネル名は最大約 **10 バイト**（英文字は1文文字；中で国語は約 **5 个漢文字**）。漢文字を含まない場合、双守界面できます能を周波数とチャンネル名表示位置が入れ替わります（见 FAQ #3）。

> 中で国語を表示するには対応フォントを書き込み、 **显示 → 表示言語** で中で国語を選択。

### 入力モード

命名界面短押し **`#`（F）** 順に切り替える（中で国語界面通常はピンインから開始）：

| モード | 説明 |
|------|------|
| ピンイン | T9ピンイン → 漢文字を選択 |
| 小文文字／大文文字 | マルチタップ英文字 |
| 数文字 | 数文字のみ |
| 符号 | 記号ページ |

ポイント：

- ピンイン：**2～9**で音節をテンキー入力；**↑/↓** 候補を切り替える；**\*** バックスペース。
- 非ピンインで長押し `#` できます插入 `#`；数文字を長押しすると、その数文字を強制入力。
- 長押し `EXIT` 編集モードを終。

#### ピンインキー対応表（T9）

## 1.8 MDC IDと送信終音

現でのファームウェアでは引き続き使用 **MDC1200**（Yan ID 替换方案见设计文档、**未実装**）。

1. **MENU** → **その他** → **送信終音（Roger）**：選択できます能 **关 / ROGER / MDC / Yan ID / Custom1 / Custom2 / Custom3**（中で英語界面均として Custom1/2/3）。
   - **Custom1**：四音短响（1975→2100→3140→2800 Hz、间隙 10ms）
   - **Custom2**：430 Hzのビープを3回（350ms 音 / 350ms 停）
   - **Custom3**：三音で坠（1650→1100→750 Hz）
2. 選択 **MDC** 时、できますで **MDC ID** メニュー4桁の16進ユニットIDを編集（として0000时、0000の場合は未入力として扱い、送信しません）。
3. 相手がMDCを送信し、本機のRogerがMDCの場合、メイン画面できます弹出 **MDC ID** 受信通知。

設定バックアップ中で MDC ID 位于 SPI `0x00A172`（2 バイト）、见第二章アドレス表。

## 1.9 デュアルPTT

で**MAIN ONLY以外**（双守 / クロスバンド等デュアルチャンネルのメイン画面）时、できますを**サイドキー1またはサイドキー2** 做成2系統目のPTT：ハードウェアPTTは送信**上で面主チャンネル**、PTTを割り当てたサイドキーを押して送信**で面副チャンネル**。

### 有効にする方法

1. 受信モードを確認**不是** MAIN ONLY（メニュー内で選択双守またはクロスバンド、主页显示上で两条チャンネル）。
2. **MENU** → **サイドキー 1 短押し/長押し**、または **サイドキー 2 短押し/長押し**。
3. 动作列表内で選択 **PTT** し確認する。
4. 该サイドキーの另一槽位します**自动**也变成 PTT；系统しますを **PTT設定** 强制として**经典**（押す住说话）。
5. デュアルPTT **1つのサイドキーにのみ割り当てできます**：给サイドキー 2 绑 PTT 时、サイドキー 1 上での PTT します自動のに解除されます（反之亦然）。

別の動作を再割り当て（または切回 MAIN ONLY）即できますオフデュアルPTT。

### 送信ルール

| 操作 | 行として |
|------|------|
| ハードウェアPTTを押している間 | 打**上で面**主チャンネル |
| PTTを割り当てたサイドキーを押している間 1 または 2 | 打**で面**副チャンネル（整颗キー都是对讲、不再触发原短押し/長押し动作） |
| 2つのキーを同時に押している間 | **ハードウェアPTTが優先されます**、打主チャンネル |
| 離した後 | 主チャンネル仍停で原来の那条、**上では入れ替わりません** |

### MAIN ONLYとの関係

- デュアルPTT **只でMAIN ONLY以外** 时生效。
- MAIN ONLYに切り替えると、サイドキー上での PTT 绑定します保留、但**押しても送信しません**；MAIN ONLYを離れると自動のに復元します。
- メニュー列表 MAIN ONLY では也できます能仍能看到 PTT、但**保存するは反映されません**；先にMAIN ONLYを離れてから割り当ててください。

### サブチャンネル送信時の画面

押すメニュー内で「マイク／送信アニメーション」関連設定する：

| モード | 副チャンネル送信时 |
|------|----------------|
| **オフ** | サブチャンネルのチャンネル名／周波数を反転表示 |
| **バー** | 同様に反転表示し、メインチャンネル上で部に音量バー／波形を表示 |
| **ポップアップ** | 送信ポップアップのみ表示し、行内にはTXを別表示しません |

### 注意

- ～と混同しないでください **PTT設定**（经典 / 一キー）搞混：那一项只改**硬件 PTT** 是押す住还是点押す开关、**不します**打开デュアルPTT。
- **PTT** サイドキー1／2の短押し／長押し一覧にのみ表示されます；MENU 長押し列表没有这一项。
- デュアルPTT 开着时、绑 PTT の那颗サイドキーメニューで内でナビゲーションには使用できません（请↑／↓を使って または另一颗サイドキー）。

# 第2章 ファームウェアの説明と書き換え

ようこそ **叮咚鶏ファームウェア書き換えサイト**。本章ではブラウザーでの校正バックアップ、ファームウェア・フォント・設定の書き込み、周波数書き込み、起動画面画像、およびストレージアドレス等技術细节。

## 2.1 準備と推奨手順

1. **Chrome**または**Edge**を使用してください（Web Serial対応が必要です）。
2. 純正プログラミングケーブルで無線機とPCを接続します。
3. **初めてサードパーティ製ファームウェアを書き込む前に**、必ず**純正ファームウェア、通常起動使用界面**で先 **校正をバックアップ**。

**推荐顺序：**

1. 校正をバックアップ（純正、通常起動）  
2. ファームウェアを書き込む（BOOT モード：電源オフ后押す住 **PTT** 再起動）  
3. フォントを書き込む（通常起動；中で国語メニュー/チャンネル名必要です要）  
4. 検証／校正を復元（通常起動）  
5. 周波数書き込み／起動画面画像／設定バックアップ（必要に応じて）  

各手順はWebサイトの対応タブに従ってください。

## 2.2 校正をバックアップ

校正データには RSSI、バッテリー電圧、VOX 等ハードウェアパラメータ、正常動作に重要です。

**操作手順：**

1. デバイスを通常起動して使用画面に入る（BOOTには入らないでください）
2. USBを接続
3. Webページで選択「校正をバックアップ」
4. 点击「校正データをエクスポート」
5. ダウンロード `calibration.dat`（512 バイト）

**技術仕様：**

- ～を通じてデバイス信息请求ファームウェアバージョンを自動判定し、校正領域のアドレスを選択します  
- **校正区 EEPROM 論理アドレス：**
  - ファームウェア **v5.0.0 および以上で**：`0xB000`
  - ファームウェア **v5.0.0 未満**：`0x1E00`
- 16バイトずつ読み出し、合計512バイト  
- 物理保存する先で SPI Flash `0x010000`–`0x0101FF`（见 2.5）

## 2.3 校正を復元

**操作手順：**

1. 通常起動入る使用界面  
2. USBを接続 →「校正を復元」  
3. 以前の `calibration.dat`（512バイトである必要があります）  
4. 復元をクリックすると、完後にデバイスが自動再起動します  

**重要事項：**

- ⚠️ **本サイトとUVTools2のバックアップファイルのみ対応**  
- ⚠️ **復元前に必ず通常起動してください**、不能刷机 BOOT では操作  
- 書き込み完後に自動再起動  

**技術仕様：** とバックアップ相同のバージョン识别とアドレス；每次写 16 バイト；完成后发再起動命令。

## 2.4 校正アドレスとデータ構造

**保存する場所：**

| 記憶媒体 | アドレス範囲 | 用途 | サイズ |
|---------|---------|------|------|
| EEPROM 逻辑 | `0x1E00`（v4+） | 校正データ | 512B |
| EEPROM 逻辑 | `0xB000`（v5+） | 校正データ | 512B |
| SPI Flash | `0x010000` – `0x010200` | 校正データバックアップ区 | 512B |

**アドレス変更の理由：** v5.0.0 起校正区从 `0x1E00` へ移動 `0xB000`；Webページ工具自动识别バージョン。两套論理アドレスいずれも同じSPI領域にマッピングされます。

**校正データ構造（校正領域からの相対オフセット）：**

- `+0xC0` ~ `+0xD0`：RSSI  
- `+0x140` ~ `+0x14C`：バッテリー電圧  
- `+0x150` ~ `+0x160`：VOX 灵敏度  
- `+0x168` ~ `+0x178`：VOX 阈值  
- `+0x188` ~ `+0x198`：晶振、音量ゲイン等  

**互換性：** 異なるWebサイトの形式は互換性がない場合があります；ファームウェア更新前にバックアップしてください；校正の破損は～として現れる場合がありますバッテリー残量乱跳、信号不准、花屏等。

## 2.6 SPI Flash ストレージアドレス映射

## 2.8 書き換え関連FAQ

（完全なFAQは第3章を参照；此处抽出刷机向问答。）

1. **書き込み直後に英語表示になる？**  
   対応するフォントを書き込む、し **显示 → 表示言語** 選択で文。

2. **文鎮化？**  
   対象機種ではないファームウェアを書き込んでいないか、別の周波数書き込み／校正ツールを使用していないか？アドレス構成はファームウェアによって異なります、周波数書き込みソフトは共通ではありません。必ず押す本站步骤操作。

3. **别人フォント正常我缺文字？**  
   フォントとファームウェアバージョン不一致、または浏览器缓存旧フォント文件——キャッシュを消去してから再書き込み。

4. **純正ファームウェアへ戻す際にパスワードを要求される？**  
   メニュー **「その他」→「工場出荷状態へ戻す」→「純正」(OEM)** → 確認する → 见「電源を切ってください」后電源オフ → 公式CPSで純正ファームウェアを書き込む。该選択项します擦除含 AES 写频密钥の区域、避免 CPS 要密码。详情见Webサイト应急工具箱同名教程。建议加微信群求助（Webサイト右侧悬浮入口）。

5. **ノイズ画面／バッテリー残量の乱高で／電圧の不正確さ？**  
   校正异常：復元純正校正；もし未バックアップ、できます用Webページ提供の純正校正。

1. **「チャンネル」→「出力」内で显示「用 xxx」とは何ですか？**  
   答：ユーザーが **「その他」→「設定する出力」** 中でカスタムした出力レベル、ここに表示されます。

2. **刚刷入ファームウェア显示英語？**  
   答：必要です刷入对应フォント、し **显示 → 表示言語** 選択择で文。

3. **双チャンネル时有时で方显示チャンネル名、有时显示周波数？**  
   答：仕様です。チャンネル名漢文字を含まない場合、で方显示周波数、左上で角显示チャンネル名。チャンネル名は最大約5文文字の漢文字（约 15 个英語文文字）、収まらない場合は表示位置が入れ替わります。

4. **文鎮化？**  
   答：是否刷不属于你机器のファームウェア？是否用その他写频工具または乱改校正？是否严格押すWebページ刷机步骤执行？  
   > 各ファームウェア内存アドレス用法不同、周波数書き込みソフトは共通ではありません。～の許可なく验证の软件导致文鎮化自负。

5. **别人フォント正常、我缺某些文字？**  
   答：フォントとファームウェアバージョン不一致、または浏览器缓存旧文件。キャッシュを消去してから再書き込み匹配バージョン。

6. **ラジオのバンドが合わない？**  
   答：でラジオ画面用 **`1` / 長押し `1` / `F+1`** 国・地域のバンドを切り替える。详见 [1.2](#12-ラジオの開き方と使い方)。

7. **本体はK1なのにシステム情報がK5と表示される？**  
   答：ユーザー設定です。できます同時に押す住 **PTT** とで方紧挨サイドキー起動以解锁関連選択项；バッテリータイプを対応機種に設定。界面通常只显示 K1 または K5（K5/K6 本质同芯、外壳不同）。

8. **トーンなどのパラメータを変更しても、チャンネル切替や再起動で消える？**  
   答：**チャンネルモードで変更参数后、必ず再执行「チャンネル保存する」**、否则只是临时更改。详见 [1.4](#14-チャンネルの保存する方法)。

9. **#長押しでキーロックするとPTTまでロックされる？**  
   答：**「その他」→「ロック範囲」** 選択できます能只キーロックまたは连同 PTT。

10. **純正ファームウェアへ戻す際にパスワードを要求される？**  
    答：用 **「その他」→「工場出荷状態へ戻す」→「純正」(OEM)**、確認する后见「電源を切ってください」再電源オフ、用公式 CPS 刷純正。详见Webサイト应急工具箱教程。建议加微信群（Webサイト右侧悬浮）。

11. **雪花屏 / バッテリー残量飘忽 / 電圧不对？**  
    答：校正问题、復元純正校正；未バックアップできます用Webページ純正校正。

12. **ラジオ使用中でにアマチュアチャンネルへ信号が来ると、割り込み終する場合としない場合がある？**  
    答：双守でのみ当**主チャンネル**有信号才打断終ラジオ。BK4819 真のデュアル待受はできず、ポーリングで実現します；ラジオモードでもし持续轮询します损害收音质量し更耗电。

13. **なぜ特に電池を消費しているように見え、残量が目で分かるほど変化するのか？**  
    答：送受信時の電流変化により電圧表示が変動します、类似老式电动车拧油门バッテリー残量瞬降。正常な現象です。一部その他ファームウェア送信时不刷新バッテリー残量、看起来更“稳”。

14. **全バンドをアンロックすると何が使えるか？ハードウェア制限はあるか？？**  
    答：受 **BK4819** 限制：Band1 约 18–630 MHz、Band2 约 84–1300 MHz；**630–840 MHz としてハードウェアのデッドゾーン**、ファームウェア回避できません。

    **解锁すべて（すべてアンロック / F_LOCK_NONE）おおよその使用できます能範囲：**

    | モード | 受信（RX） | 送信（TX） |
    |------|-----------|-----------|
    | 標準モード | 50 MHz ~ 600 MHz | 50 MHz ~ 600 MHz |
    | 広帯域受信モード | 18 MHz ~ 1300 MHz（デッドゾーンを除く） | 18 MHz ~ 600 MHz + 470 MHz ~ 1300 MHz |

    **メニュー「バンドロック」主な項目（と現でのファームウェア一致、含编译开关项）：**

    | モード | 説明（送信関連） |
    |------|------------------|
    | デフォルト | 137–174 / 400–470 |
    | FCC 业余 | 144–148 / 420–450 |
    | CA 业余 | 144–148 / 430–450（コンパイル時に有効な場合） |
    | CE 业余 | 144–146 / 430–440 |
    | GB 业余 | 144–148 / 430–440 |
    | 137–174 / 400–430 | 分区表 |
    | 137–174 / 400–438 | 分区表 |
    | PMR 446 | コンパイル時に有効な場合 |
    | GMRS/FRS/MURS | コンパイル時に有効な場合 |
    | すべて無効 | 禁发 |
    | すべてアンロック | 必要ですメニューで約**10回**連続して選択すると有効になります（防误触） |

    **その他：**

    - 约 280 MHz として VHF/UHF 分界、影响滤波とPAゲイン  
    - 広帯域受信では短波から1.3 GHzまで受信できます、送信は引き続きバンド表の制限を受けます

1. 短按 **MENU** 进入菜单。
2. **↑/↓** 或数字键快速跳转菜单项；再按 **MENU** 进入子项。

| 模式 | 说明 |

## 1.2 如何打开与使用收音机

叮咚鸡使用机内 **BK1080** 做调频广播，通过**独立的收音机页面**收听（不是主界面调制里的 WFM）。

### 进入 / 退出

1. 主界面 **`长按0`** 或 **`F+0`** 进入收音机。
2. 再按 **`F+0`**，或短按 **EXIT**（无保存/删除提示时）退出回主界面。

### 频率模式与信道模式（收音机内）

- 收音机内短按 **`3`** 或 **`F+3`**：在 **频率（VFO）** 与 **信道（MR）** 之间切换。
- **频率模式**：用数字键输入频率，或 **↑/↓** 调谐。
- **信道模式**：在已保存的收音机预设台之间切换。

### 切换国家频段

- 收音机页面下 **短按 `1`** 或 **`F+1`** / **长按 `1`**：切换所在国家/地区频段（频段不对时先切换再搜台）。

### 保存 / 删除收音机预设

**频率模式下保存当前频率到预设列表：**

1. 调好频率后短按 **MENU**，出现「保存?」。
2. 用 **↑/↓** 选择预设槽位。
3. 再按 **MENU** 确认保存。

**信道（MR）模式下删除当前预设：**

1. 短按 **MENU**，出现「删除?」。
2. 再按 **MENU** 确认删除。

也可用网站「写频」相关能力管理部分配置；收音机选中频率/频道/MR/频段会写入配置区（见第二章）。

### 扫描电台

| 操作 | 效果 |
|------|------|
| **长按 `*`** 或 **`F+*`** | 清空预设列表后全频段搜索（A-SCAN），有信号的频率会存入列表 |
| 短按扫描相关操作 | 在已有列表上扫描（M-SCAN，界面有提示） |

停止扫描：短按 **EXIT** 或 **MENU**（视当前状态）。

### 其它按键

| 按键 | 功能 |
|------|------|
| `F+8` | 背光（按需） |
| `F+9` | 背光开关相关 |
| `F+0` | 退出收音机 |

### 注意

- 双守时：仅当**主信道**来业余信号时，才会打断并退出收音机（见 FAQ）。
- 收音机占用 BK1080；与双守轮询互斥策略见第三章 FAQ #12。

## 1.3 如何扫描

### 扫描记忆信道列表

1. 先给每个信道设置所属扫描列表：网页「写频」写入，或菜单 **「信道」→「信道列表」**。
2. **MENU** → **「其它」→「扫描列表」**，选择要扫的列表。
3. 主界面处于**信道模式**，**长按 `*`** 或 **`F+*`** 开始扫描。
4. 扫到有信号的信道后，按 **MENU** 停在该信道；无信号时 **MENU** / **EXIT** 均可退出扫描。

### 一键扫频与扫描亚音

1. **长按 `4`** 或 **`F+4`**：一键扫频。
2. **频率模式**下 **`F+*`**：开启扫描亚音（CTCSS/DCS）。

扫到结果后，可按提示 **MENU** →「保存?」→（信道模式时可选信道号）→ 再 **MENU** 确认，写入记忆信道。**EXIT** 取消。

### 范围扫描与频谱入口

1. 切换为**双守**模式（单守下范围扫描不可用），且“显示”中“频谱显示”选择“简单”。
2. A、B 均切换为**频率模式**。
3. A 输入起始频率，B 输入结束频率。
4. **长按 `5`**：进入范围扫描（长按 **EXIT** 退出）。
5. **`F+5`**：进入频谱页面（详见 1.6）。

### 扫描中排除信道

扫描暂停在某一信道上时，**长按 MENU** 可将该信道从当前扫描中排除（视固件提示）。

### 相关菜单

| 菜单 | 作用 |
|------|------|
| 扫描列表 | 选择默认列表 / 全部等 |
| 优先扫描、优先信道 | 优先信道 |
| 扫描恢复 | 遇信号后停止 / 载波 / 超时等 |

## 1.4 如何保存信道

把当前频率与参数写入记忆信道。

### 方法一：菜单「存信道」

1. 在主界面调好频率、亚音、功率、调制、偏移等。
2. 短按 **MENU** → **存信道（ChSave）** → 再按 **MENU**。
3. 用 **↑/↓** 或输入信道号，选择目标信道。
4. 按 **MENU** → 出现「确认?」后再按 **MENU** 完成保存。

删除：菜单 **删信道（ChDele）**，同样需确认。

也可用网站「写频」页批量导入信道。

### 方法二：信道模式下改参后必须再存

在**信道模式（MR）**下，通过菜单修改该信道的亚音、功率、带宽等时：

- 修改后**当时**可能已按新参数工作；
- **若不执行「存信道」**，一切换信道或开机，修改会丢失（视为临时更改）。

**正确做法：** 改完参数后，再走一遍 **存信道（ChSave）**，把当前参数写回该记忆信道。

### 方法三：扫描结果保存

一键扫频 / 亚音扫描结束后，按界面「保存?」流程写入信道（见 1.3）。

## 1.9 双 PTT

在**非 MAIN ONLY**（双守 / 跨段等双信道主页）时，可把**侧键 1 或侧键 2** 做成第二路 PTT：硬件 PTT 打**上面主信道**，绑了 PTT 的那颗侧键按住打**下面副信道**。

### 如何开启

1. 确认接收模式**不是** MAIN ONLY（菜单里选双守或跨段，主页显示上下两条信道）。
2. **MENU** → **侧键 1 短按/长按**，或 **侧键 2 短按/长按**。
3. 动作列表里选 **PTT** 并确认。
4. 该侧键的另一槽位会**自动**也变成 PTT；系统会把 **设置 PTT** 强制为**经典**（按住说话）。
5. 双 PTT **只能绑在一颗侧键上**：给侧键 2 绑 PTT 时，侧键 1 上的 PTT 会自动取消（反之亦然）。

再绑一次其它动作（或切回 MAIN ONLY）即可关闭双 PTT。

### 发射规则

| 操作 | 行为 |
|------|------|
| 按住硬件 PTT | 打**上面**主信道 |
| 按住绑了 PTT 的侧键 1 或 2 | 打**下面**副信道（整颗键都是对讲，不再触发原短按/长按动作） |
| 两键同时按住 | **硬件 PTT 优先**，打主信道 |
| 松开后 | 主信道仍停在原来的那条，**上下不换位** |

### 与 MAIN ONLY 的关系

- 双 PTT **只在非 MAIN ONLY** 时生效。
- 切到 MAIN ONLY 时，侧键上的 PTT 绑定会保留，但**按住不会发射**；离开 MAIN ONLY 后自动恢复。
- 菜单列表在 MAIN ONLY 下也可能仍能看到 PTT，但**保存不会生效**；需先离开 MAIN ONLY 再绑。

### 副信道发射时的界面

按菜单里「话筒 / 发射动画」相关设置：

| 模式 | 副信道发射时 |
|------|----------------|
| **关闭** | 副信道信道名 / 频率反色 |
| **条形** | 同上反色，并在主信道顶栏画声音条 / 波形 |
| **弹窗** | 只显示发射弹窗，行内不另画 TX |

### 注意

- 不要和 **设置 PTT**（经典 / 一键）搞混：那一项只改**硬件 PTT** 是按住还是点按开关，**不会**打开双 PTT。
- **PTT** 只出现在侧键 1 / 侧键 2 的短按 / 长按列表；MENU 长按列表没有这一项。
- 双 PTT 开着时，绑了 PTT 的那颗侧键在菜单里不能再用来导航（请用 ↑/↓ 或另一颗侧键）。

# 第二章 固件说明与刷机

欢迎使用 **叮咚鸡刷机网站**。本章说明浏览器内备份校准、刷固件、字库、配置、写频与开机图，以及存储地址等技术细节。

## 2.1 准备工作与推荐顺序

1. 使用 **Chrome** 或 **Edge**（需支持 Web Serial）。
2. 原厂编程线连接手台与电脑。
3. **首次刷第三方固件前**，务必在**原厂固件、正常开机使用界面**下先 **备份校准**。

**推荐顺序：**

1. 备份校准（原厂、正常开机）  
2. 刷固件（BOOT 模式：关机后按住 **PTT** 再开机）  
3. 刷字库（正常开机；中文菜单/信道名需要）  
4. 校验 / 恢复校准（正常开机）  
5. 写频 / 开机图片 / 备份配置（按需）  

各步骤以网站对应页签为准。

## 2.2 备份校准

校准数据包含 RSSI、电池电压、VOX 等硬件参数，对正常工作至关重要。

**操作步骤：**

1. 设备正常开机进入使用界面（不要进 BOOT）
2. 连接 USB
3. 网页选择「备份校准」
4. 点击「导出校准数据」
5. 下载 `calibration.dat`（512 字节）

**技术实现：**

- 通过设备信息请求自动识别固件版本并选择校准区地址  
- **校准区 EEPROM 逻辑地址：**
  - 固件 **v5.0.0 及以上**：`0xB000`
  - 固件 **v5.0.0 以下**：`0x1E00`
- 每次读 16 字节，共 512 字节  
- 物理落盘在 SPI Flash `0x010000`–`0x0101FF`（见 2.5）

## 2.3 恢复校准

**操作步骤：**

1. 正常开机进入使用界面  
2. 连接 USB →「恢复校准」  
3. 选择此前的 `calibration.dat`（必须 512 字节）  
4. 点击恢复；完成后设备自动重启  

**重要提示：**

- ⚠️ **仅支持本站和 UVTools2 的备份文件**  
- ⚠️ **恢复前必须正常开机**，不能在刷机 BOOT 下操作  
- 写入完成后自动重启  

**技术实现：** 与备份相同的版本识别与地址；每次写 16 字节；完成后发重启命令。

## 2.4 校准地址与数据结构

**存储位置：**

| 存储介质 | 地址范围 | 用途 | 大小 |
|---------|---------|------|------|
| EEPROM 逻辑 | `0x1E00`（v4+） | 校准数据 | 512B |
| EEPROM 逻辑 | `0xB000`（v5+） | 校准数据 | 512B |
| SPI Flash | `0x010000` – `0x010200` | 校准数据备份区 | 512B |

**地址变更原因：** v5.0.0 起校准区从 `0x1E00` 迁到 `0xB000`；网页工具自动识别版本。两套逻辑地址均映射到同一 SPI 区域。

**校准数据结构（相对校准区偏移）：**

- `+0xC0` ~ `+0xD0`：RSSI  
- `+0x140` ~ `+0x14C`：电池电压  
- `+0x150` ~ `+0x160`：VOX 灵敏度  
- `+0x168` ~ `+0x178`：VOX 阈值  
- `+0x188` ~ `+0x198`：晶振、音量增益等  

**兼容性：** 不同网站格式可能不兼容；刷新固件前先备份；校准损坏可表现为电量乱跳、信号不准、花屏等。

## 2.6 SPI Flash 存储地址映射

用户数据主要在 **PY25Q16 SPI Flash（2 MB，`0x000000`–`0x1FFFFF`）**。MCU 片内 Flash（`0x08002800` 起）仅放程序。

网页写频与固件多直接用 **SPI 物理地址**；旧工具的 **EEPROM 逻辑地址** 由 `eeprom_compat` 映射到 SPI。

### 存储介质概览

| 介质 | 地址范围 | 容量 | 用途 |

### 中文字库与拼音索引

| SPI 物理地址 | 大小 | 内容 |
|-------------|------|------|

| `0x056236` | 1 B | 字库版本号（当前 = 2） |

旧版中文信道名：`0x020000`–`0x023FFF`（与字库不重叠）。  
**现行固件**：启动时若该区非空，会一次性把有效中文名迁到统一信道名区 `0x004000`，随后擦除本区；迁移完成后**不再读写**。中英文信道名均只存 `0x004000`。该 16 KB 仅作旧机兼容导入用，**后续 Flash 规划可回收**（勿在迁移逻辑仍保留时放活数据）。

## 2.8 刷机相关 FAQ

（完整 FAQ 见第三章；此处抽出刷机向问答。）

1. **刚刷入显示英文？**  
   刷对应字库，并在 **显示 → 显示语言** 选中文。

2. **变砖？**  
   是否刷了非本机固件、用了其它写频/改校准工具？地址布局因固件而异，写频软件不通用。务必按本站步骤操作。

3. **别人字库正常我缺字？**  
   字库与固件版本不一致，或浏览器缓存了旧字库文件——清理缓存后重刷。

4. **刷回原厂要密码？**  
   菜单 **「其它」→「恢复出厂」→「原厂」(OEM)** → 确认 → 见「请关机」后关机 → 用官方 CPS 刷原厂固件。该选项会擦除含 AES 写频密钥的区域，避免 CPS 要密码。详情见网站应急工具箱同名教程。建议加微信群求助（网站右侧悬浮入口）。

5. **雪花屏 / 电量乱跳 / 电压不准？**  
   校准异常：恢复原厂校准；若未备份，可用网页提供的原厂校准。

# 第三章 常见问题与其它

## 3.1 常见问题

1. **「信道」→「功率」里显示「用 xxx」是什么意思？**  
   答：用户在 **「其它」→「设置功率」** 中自定义的功率档，此处回显。

2. **刚刷入固件显示英文？**  
   答：需刷入对应字库，并在 **显示 → 显示语言** 选择中文。

3. **双信道时有时下方显示信道名、有时显示频率？**  
   答：设计如此。信道名不含汉字时，下方显示频率、左上角显示信道名。信道名最多约 5 个汉字（约 15 个英文字母），放不下时会互换显示位置。

4. **变砖了？**  
   答：是否刷了不属于你机器的固件？是否用了其它写频工具或乱改校准？是否严格按网页刷机步骤执行？  
   > 各固件内存地址用法不同，写频软件不通用。未经验证的软件导致变砖自负。

5. **别人字库正常，我缺某些字？**  
   答：字库与固件版本不一致，或浏览器缓存旧文件。清理缓存后重刷匹配版本。

6. **收音机频段不对？**  
   答：在收音机页面用 **`1` / 长按 `1` / `F+1`** 切换国家频段。详见 [1.2](#12-如何打开与使用收音机)。

7. **机器是 K1，系统信息却显示 K5？**  
   答：用户自定义。可同时按住 **PTT** 与下方紧挨侧键开机以解锁相关选项；电池类型选对应机型。界面通常只显示 K1 或 K5（K5/K6 本质同芯，外壳不同）。

8. **改了亚音等参数，切换信道或开机就没了？**  
   答：**信道模式下修改参数后，必须再执行「存信道」**，否则只是临时更改。详见 [1.4](#14-如何保存信道)。

9. **长按 # 锁键盘时连 PTT 也锁了？**  
   答：**「其它」→「锁键范围」** 可选只锁键盘或连同 PTT。

10. **刷回原厂要密码？**  
    答：用 **「其它」→「恢复出厂」→「原厂」(OEM)**，确认后见「请关机」再关机，用官方 CPS 刷原厂。详见网站应急工具箱教程。建议加微信群（网站右侧悬浮）。

11. **雪花屏 / 电量飘忽 / 电压不对？**  
    答：校准问题，恢复原厂校准；未备份可用网页原厂校准。

12. **收音机时业余信道来信号，有时打断退出有时不？**  
    答：双守下仅当**主信道**有信号才打断退出收音机。BK4819 不能真双守，靠轮询；收音机模式下若持续轮询会损害收音质量并更耗电。

13. **为什么看起来特别耗电、电量肉眼可见变化？**  
    答：收发时电流变化导致电压表跳动，类似老式电动车拧油门电量瞬降。属正常现象。部分其它固件发射时不刷新电量，看起来更“稳”。

14. **解锁全部频段能用哪些？受硬件限制吗？**  
    答：受 **BK4819** 限制：Band1 约 18–630 MHz，Band2 约 84–1300 MHz；**630–840 MHz 为硬件死区**，固件无法绕过。

    **解锁全部（全部解锁 / F_LOCK_NONE）大致可用范围：**

    | 模式 | 接收（RX） | 发射（TX） |
    |------|-----------|-----------|
    | 标准模式 | 50 MHz ~ 600 MHz | 50 MHz ~ 600 MHz |
    | 宽带接收模式 | 18 MHz ~ 1300 MHz（排除死区） | 18 MHz ~ 600 MHz + 470 MHz ~ 1300 MHz |

    **菜单「锁定频段」常见选项（与当前固件一致，含编译开关项）：**

    | 模式 | 说明（发射相关） |
    |------|------------------|
    | 默认 | 137–174 / 400–470 |
    | FCC 业余 | 144–148 / 420–450 |
    | CA 业余 | 144–148 / 430–450（若编译启用） |
    | CE 业余 | 144–146 / 430–440 |
    | GB 业余 | 144–148 / 430–440 |
    | 137–174 / 400–430 | 分区表 |
    | 137–174 / 400–438 | 分区表 |
    | PMR 446 | 若编译启用 |
    | GMRS/FRS/MURS | 若编译启用 |
    | 全部禁用 | 禁发 |
    | 全部解锁 | 需在菜单中连续选择约 **10 次** 才激活（防误触） |

    **其它：**

    - 约 280 MHz 为 VHF/UHF 分界，影响滤波与功放增益  
    - 宽带接收可听短波到 1.3 GHz，发射仍受频段表限制
