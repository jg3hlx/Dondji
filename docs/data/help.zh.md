# 第1章 システム使用マニュアル

ようこそ **叮咚鸡（Dondji）**。本章では起動後の基本操作を説明します。ファームウェア書き込み、校正、設定のバックアップについては第2章を参照してください。

## 1.1 基本操作

### 電源のオン／オフと音量

- ノブを押して電源をオン／オフし、回して音量を調整します。
- 机身 **`#` キーは F キーです**（短押しで F キーとの組み合わせ操作、長押しでキーロック）。

### メニューを開く

1. 短押し **MENU** メニューを開きます。
2. **↑/↓** または数字キーでメニュー項目に移動し、もう一度 **MENU** サブ項目に入ります。
3. **EXIT** 1つ上の階層に戻るか、メニューを終了します。

### 周波数モード（VFO）与メモリーチャンネルモード（MR）

| モード | 说明 |
|------|------|
| **周波数モード（VFO）** | 周波数を直接調整します。ステップ幅や変調方式などを変更できます |
| **メモリーチャンネルモード（MR）** | 保存済みのメモリーチャンネルを呼び出します |

- 短押し **`3`** 或 **`F+3`** / 長押し **`3`**：VFO と MR を切り替えます。
- **メモリーチャンネルモード下変更トーン、出力、周波数偏移等参数后，只是临时生效；必须再执行一次「存チャンネル」，切换チャンネル或起動后才会保留。** 详见 [1.4 チャンネルの保存方法](#14-チャンネルの保存方法)。
- メモリーチャンネルモード下 **`F+1`**：把当前チャンネル复制到对应周波数帯的 VFO，并切到周波数モード（便于微调后再存回）。

### A / B 双频与受信モード

- **`F+2`** / 長押し **`2`**：A/B を切り替えます（メインチャンネルモードでは無効の場合があります）。
- 受信モード（単独待受／デュアル待受／クロスバンドなど）はメニューで設定します。単独待受とデュアル待受の画面例を以下に示します。

**単独待受画面：**

![単独待受页面示意](images/main_only_s.png)

**デュアル待受画面：**

![デュアル待受页面示意](images/AB_s.png)

### よく使うキー（メイン画面）

| キー | 功能 |
|------|------|
| `長押し1` 或 `F+1` | VFO 下：切换周波数帯起始周波数；MR 下：`F+1` 将チャンネル复制到 VFO |
| `長押し2` 或 `F+2` | 切换 A/B チャンネル（仅主メモリーチャンネルモード下可能禁用） |
| `長押し3` 或 `F+3` | 切换メモリーチャンネルモード / 周波数モード |
| `長押し4` 或 `F+4` | ワンタッチ周波数スキャン |
| `F+5` | スペクトラム画面を開く |
| `長押し5` | デュアル待受 + 双 VFO 时：範囲スキャン（见 1.3） |
| `長押し6` 或 `F+6` | 切换出力 |
| `長押し8` | リバース（送受信周波数を入れ替え） |
| `F+8` | バックライトモードを切り替え |
| `長押し9` | 跳到「その他」→「キー即呼」中设置的チャンネル |
| `長押し0` 或 `F+0` | ラジオを開く |
| メモリーチャンネルモード `長押し*` 或 `F+*` | スキャン当前スキャン一覧 |
| 周波数モード `長押し*` | 周波数向上スキャン |
| 周波数モード `F+*` | スキャントーン |
| `長押し#`（F） | キーロック。再度長押しすると解除 |
| `F+↑` / `F+↓` | スケルチを調整（若ファームウェア启用） |
| `F+侧键` | ステップ幅を調整（若ファームウェア启用） |

### メニュー操作の概要

- **方向キー**：切换メニュー  
- **MENU**：確定  
- **EXIT**：終了  
- **数字键**：快速跳转

## 1.2 ラジオの起動と使い方

叮咚鸡本機内蔵の **BK1080** を FM ラジオに使用します，通过**独立的ラジオ页面**收听（不是主画面调制里的 WFM）。

### 起動／終了

1. 主画面 **`長押し0`** 或 **`F+0`** ラジオを起動します。
2. 再按 **`F+0`**，或短押し **EXIT**（无保存/削除提示时）終了してメイン画面に戻ります。

### 周波数モード与メモリーチャンネルモード（ラジオ内）

- ラジオ内短押し **`3`** 或 **`F+3`**：在 **周波数（VFO）** 与 **チャンネル（MR）** 之间切换。
- **周波数モード**：用数字键入力周波数，或 **↑/↓** 调谐。
- **メモリーチャンネルモード**：在已保存的ラジオ预设台之间切换。

### 国・地域の周波数帯を切り替える

- ラジオ页面下 **短押し `1`** 或 **`F+1`** / **長押し `1`**：切换所在国家/地区周波数帯（周波数帯不对时先切换再搜台）。

### ラジオのプリセットを保存／削除する

**周波数モード下現在の周波数をプリセット一覧に保存する：**

1. 调好周波数后短押し **MENU**，出现「保存?」。
2. 用 **↑/↓** 選択预设槽位。
3. 再按 **MENU** 確定保存。

**チャンネル（MR）モード下現在のプリセットを削除する：**

1. 短押し **MENU**，出现「削除?」。
2. 再按 **MENU** 確定削除。

ウェブサイトの「周波数書き込み」機能で一部設定を管理することもできます。ラジオで選択した周波数／チャンネル／MR／周波数帯は設定領域に保存されます（第2章参照）。

### 放送局をスキャンする

| 操作 | 效果 |
|------|------|
| **長押し `*`** 或 **`F+*`** | プリセット一覧を消去して全周波数帯を検索（A-SCAN）し、信号のある周波数を一覧に保存します |
| 短押しスキャン相关操作 | 既存の一覧をスキャンします（M-SCAN、画面に表示あり） |

スキャン停止：短押し **EXIT** 或 **MENU**（视当前状态）。

### その他キー

| キー | 功能 |
|------|------|
| `F+8` | 背光（按需） |
| `F+9` | 背光开关相关 |
| `F+0` | 終了ラジオ |

### 注意

- デュアル待受时：仅当**メインチャンネル**来业余信号时，才会打断并終了ラジオ（见 FAQ）。
- ラジオ占用 BK1080；与デュアル待受轮询互斥策略见第三章 FAQ #12。

## 1.3 スキャン方法

### メモリーチャンネル一覧をスキャンする

1. まず各チャンネルのスキャンリストを設定します。ウェブサイトの「周波数書き込み」で設定するか、メニューから **「チャンネル」→「チャンネル一覧」**。
2. **MENU** → **「その他」→「スキャン一覧」**，スキャンするリストを選択します。
3. メイン画面を**メモリーチャンネルモード**，**長押し `*`** 或 **`F+*`** スキャンを開始します。
4. 信号のあるチャンネルを検出したら、 **MENU** を押すとそのチャンネルで停止します。信号がない場合は **MENU** / **EXIT** のどちらでもスキャンを終了できます。

### ワンタッチ周波数スキャン与スキャントーン

1. **長押し `4`** 或 **`F+4`**：ワンタッチ周波数スキャン。
2. **周波数モード**下 **`F+*`**：开启スキャントーン（CTCSS/DCS）。

扫到结果后，可按提示 **MENU** →「保存?」→（メモリーチャンネルモード时可选チャンネル号）→ 再 **MENU** 確定，書き込みメモリーチャンネル。**EXIT** 取消。

### 範囲スキャン与スペクトラム入口

1. 切换为**デュアル待受**モード（単独待受下範囲スキャン不可用），且“显示”中“スペクトラム显示”選択“简单”。
2. A、B 均切换为**周波数モード**。
3. A 入力起始周波数，B 入力结束周波数。
4. **長押し `5`**：进入範囲スキャン（長押し **EXIT** 終了）。
5. **`F+5`**：スペクトラム画面を開く页面（详见 1.6）。

### スキャン対象からチャンネルを除外する

特定のチャンネルでスキャンが一時停止しているとき、**長押し MENU** を長押しすると、そのチャンネルを現在のスキャン対象から除外できます（ファームウェアの表示に従ってください）。

### 関連メニュー

| メニュー | 作用 |
|------|------|
| スキャン一覧 | 既定のリスト／すべてなどを選択 |
| 优先スキャン、優先チャンネル | 優先チャンネル |
| スキャン復元 | 信号検出時に停止／キャリア／タイムアウトなど |
| チャンネル一覧 | チャンネルをスキャンリストに含めるかどうか |

## 1.4 チャンネルの保存方法

現在の周波数とパラメーターをメモリーチャンネルに書き込みます。

### 方法1：メニューの「チャンネル保存」

1. 在主画面调好周波数、トーン、出力、调制、偏移等。
2. 短押し **MENU** → **存チャンネル（ChSave）** → 再按 **MENU**。
3. 用 **↑/↓** 或入力チャンネル号，選択目标チャンネル。
4. 按 **MENU** → 出现「確定?」后再按 **MENU** 完成保存。

削除するにはメニューの **删チャンネル（ChDele）**，を選択し、同様に確認します。

ウェブサイトの「周波数書き込み」ページからチャンネルを一括インポートすることもできます。

### 方法2：チャンネルモードで設定を変更したら再保存が必要

在**メモリーチャンネルモード（MR）**下，メニューからチャンネルのトーン、出力、帯域幅などを変更した場合：

- 変更后**当时**可能已按新参数工作；
- **「チャンネル保存」を実行しないと**，チャンネル切り替えや再起動で変更内容が失われます（一時的な変更として扱われます）。

**正しい手順：** パラメーターを変更したら、もう一度 **存チャンネル（ChSave）**，現在のパラメーターをそのメモリーチャンネルに書き戻します。

### 方法3：スキャン結果を保存する

ワンタッチ周波数スキャン / トーンスキャン结束后，按画面「保存?」流程書き込みチャンネル（见 1.3）。

## 1.5 チャンネル名の設定とピンイン入力

### 名前の編集を開始する

1. **MENU** → **命名チャンネル（ChName）**。
2. 有効なチャンネルを選択 → **MENU** 編集画面に入ります。
3. 編集が終わったら，短押し **MENU** カーソルを移動し、末尾で「確定?」保存。
4. チャンネル名は最大約 **10 字节**（英文按字符；中文约 **5 个汉字**）。漢字を含まない場合，デュアル待受画面可能把周波数与チャンネル名显示位置对调（见 FAQ #3）。

> 中国語を表示するにはフォントデータを書き込み、 **显示 → 显示言語** で中国語を選択する必要があります。

### 入力モード

名前編集画面で **`#`（F）** を短押しすると順番に切り替わります（中文画面デフォルト常从ピンイン开始）：

| モード | 说明 |
|------|------|
| ピンイン | T9 ピンイン → 选汉字 |
| 小文字／大文字 | 複数回押して文字を入力 |
| 数字 | 纯数字 |
| 符号 | 符号页 |

要点：

- ピンイン：用 **2–9** 按九键入力音节数字；**↑/↓** 翻候选；**\*** 退格。
- 非ピンイン下長押し `#` 可插入 `#`；長押し数字可强制入力该数字。
- 長押し `EXIT` 編集モードを終了します。

#### ピンインキー対応表（T9）

| キー | 字母 |
|------|------|
| **2** | A B C |
| **3** | D E F |
| **4** | G H I |
| **5** | J K L |
| **6** | M N O |
| **7** | P Q R S |
| **8** | T U V |
| **9** | W X Y Z |

示例：「山」可试 `7426`（shan）などを入力して候補から漢字を選びます。

## 1.7 MDC ID と送信終了音

現在のファームウェアは **MDC1200** 与 **Yan ID** の2種類の ID 方式に対応しています（併用可能で、互いに干渉しません）。

1. **MENU** → **その他** → **送信尾音（Roger）**：可选 **关 / ROGER / MDC / Yan ID / Custom1 / Custom2 / Custom3**（中英文画面均为 Custom1/2/3）。
   - **Custom1**：四音短响（1975→2100→3140→2800 Hz，间隙 10ms）
   - **Custom2**：三声 430 Hz 嘟（350ms 音 / 350ms 停）
   - **Custom3**：三音下坠（1650→1100→750 Hz）
2. 选 **MDC** 时，可在 **MDC ID** メニューから編集できます 4 位十六进制单元 ID（为 0000 时デフォルト未填写、不发送）；选 **Yan ID** 时，可在 **Yan ID** メニューから編集できます 6 位呼号（大写字母 / 数字）。
3. 受信通知は **MDC Rx** / **Yan Rx** メニューで個別に有効にする必要があります：对方发 MDC / Yan ID 时，主画面可弹出 ID 受信提示（MDC 若在通讯录匹配到呼号则显示呼号，否则显示十六进制 ID；Yan ID 直接显示对方呼号）。

設定バックアップでは MDC ID 位于 SPI `0x00A172`（2 字节）、Yan ID 位于 SPI `0x00A088`（8 字节），第2章のアドレス表を参照してください。

## 1.8 デュアル PTT

在**非 MAIN ONLY**（デュアル待受 / クロスバンド等双チャンネル主页）时，可把**侧键 1 或侧键 2** 做成第二路 PTT：硬件 PTT 打**上面メインチャンネル**，绑了 PTT 的那颗侧键按住打**下面サブチャンネル**。

### 有効にする方法

1. 受信モードが**不是** MAIN ONLY（メニューでデュアル待受またはクロスバンドを選択し、メイン画面に上下2つのチャンネルが表示される状態）。
2. **MENU** → **侧键 1 短押し/長押し**，或 **侧键 2 短押し/長押し**。
3. アクション一覧から **PTT** を選択して確定します。
4. 该侧键的另一槽位会**自动**也变成 PTT；系统会把 **设置 PTT** 强制为**经典**（按住说话）。
5. デュアル PTT **只能绑在一颗侧键上**：给侧键 2 绑 PTT 时，侧键 1 上的 PTT 会自动取消（反之亦然）。

別の動作を再割り当てする（または MAIN ONLY に戻す）と、デュアル PTT は無効になります。

### 送信ルール

| 操作 | 行为 |
|------|------|
| 本体の PTT を押し続ける | 打**上面**メインチャンネル |
| PTT を割り当てたサイドキー1または2を押し続ける | 打**下面**サブチャンネル（整颗键都是对讲，不再触发原短押し/長押し动作） |
| 両方のキーを同時に押す | **本体の PTT が優先**，打メインチャンネル |
| 松开后 | メインチャンネル仍停在原来的那条，**上下不换位** |

### MAIN ONLY との関係

- デュアル PTT **只在非 MAIN ONLY** 时生效。
- 切到 MAIN ONLY 时，侧键上的 PTT 绑定会保留，但**按住不会送信**；离开 MAIN ONLY 后自动復元。
- メニュー一覧在 MAIN ONLY 下也可能仍能看到 PTT，但**保存不会生效**；需先离开 MAIN ONLY 再绑。

### サブチャンネル送信時の画面

メニューの「话筒 / 送信动画」関連設定に従います：

| モード | サブチャンネル送信時 |
|------|----------------|
| **关闭** | サブチャンネルチャンネル名 / 周波数反色 |
| **条形** | 同上反色，并在メインチャンネル顶栏画声音条 / 波形 |
| **弹窗** | 只显示送信弹窗，行内不另画 TX |

### 注意

- 不要和 **设置 PTT**（经典 / 一键）搞混：その項目は**硬件 PTT** 是按住还是点按开关，**不会**打开デュアル PTT。
- **PTT** にのみ表示されます 1 / 侧键 2 的短押し / 長押し一覧；MENU 長押し一覧没有这一项。
- デュアル PTT が有効なとき，绑了 PTT 的那颗侧键在メニュー里不能再用来导航（请用 ↑/↓ 或另一颗侧键）。

# 第2章 ファームウェアの説明と書き込み

ようこそ **叮咚鸡刷机ウェブサイト**。本章说明浏览器内校正データをバックアップ、刷ファームウェア、フォントデータ、設定、写频与起動图，以及保存アドレス等技術细节。

## 2.1 準備と推奨手順

1. 使用 **Chrome** 或 **Edge**（需対応 Web Serial）。
2. 純正のプログラミングケーブルで無線機と PC を接続します。
3. **初めてサードパーティ製ファームウェアを書き込む前に**，务必在**原厂ファームウェア、正常起動使用画面**下先 **校正データをバックアップ**。

**推荐顺序：**

1. 校正データをバックアップ（原厂、正常起動）  
2. 刷ファームウェア（BOOT モード：電源オフ后按住 **PTT** 再起動）  
3. 刷フォントデータ（正常起動；中文メニュー/チャンネル名需要）  
4. 校正データを検証／復元（正常起動）  
5. 周波数書き込み／起動画面画像／設定バックアップ（必要に応じて）  

各手順はウェブサイトの該当タブに従ってください。

## 2.2 校正データをバックアップ

校正データには RSSI、バッテリー電圧、VOX などのハードウェアパラメーターが含まれ、正常動作に重要です。

**操作手順：**

1. 機器を通常起動して操作画面に入ります（不要进 BOOT）
2. USB を接続します
3. ウェブページで選択します「校正データをバックアップ」
4. 点击「エクスポート校正データ」
5. ダウンロード `calibration.dat`（512 字节）

**技術仕様：**

- 機器情報の要求を通じてファームウェアのバージョンを自動判別し、校正領域のアドレスを選択します  
- **校正領域の EEPROM 論理アドレス：**
  - ファームウェア **v5.0.0 及以上**：`0xB000`
  - ファームウェア **v5.0.0 以下**：`0x1E00`
- 1回につき16バイト、合計512バイトを読み取ります  
- SPI Flash の物理アドレスに保存されます `0x010000`–`0x0101FF`（见 2.5）

## 2.3 校正データを復元

**操作手順：**

1. 正常起動进入使用画面  
2. USB を接続します →「校正データを復元」  
3. 以前保存した `calibration.dat`（必须 512 字节）  
4. 復元をクリックします。完了すると機器が自動的に再起動します  

**重要：**

- ⚠️ **本サイトおよび UVTools2 で作成したバックアップファイルのみ対応しています**  
- ⚠️ **復元前必须正常起動**，不能在刷机 BOOT 下操作  
- 書き込み完了後、自動的に再起動します  

**技術仕様：** バックアップ時と同じバージョン判別とアドレスを使用し、1回につき16バイトを書き込みます。完了後に再起動コマンドを送信します。

## 2.4 校正アドレスとデータ構造

**保存場所：**

| 記憶媒体 | アドレス範囲 | 用途 | サイズ |
|---------|---------|------|------|
| EEPROM 逻辑 | `0x1E00`（v4+） | 校正データ | 512B |
| EEPROM 逻辑 | `0xB000`（v5+） | 校正データ | 512B |
| SPI Flash | `0x010000` – `0x010200` | 校正データバックアップ区 | 512B |

**アドレス変更の理由：** v5.0.0 から校正領域が `0x1E00` 迁到 `0xB000`；ウェブツールはバージョンを自動判別します。2つの論理アドレスは同じ SPI 領域に対応します。

**校正データ構造（校正領域からの相対オフセット）：**

- `+0xC0` ~ `+0xD0`：RSSI  
- `+0x140` ~ `+0x14C`：バッテリー電圧  
- `+0x150` ~ `+0x160`：VOX 灵敏度  
- `+0x168` ~ `+0x178`：VOX 阈值  
- `+0x188` ~ `+0x198`：晶振、音量增益等  

**互換性：** サイトによってファイル形式に互換性がない場合があります。ファームウェアを書き換える前にバックアップしてください。校正データが破損すると、電池残量や信号表示の異常、画面の乱れなどが発生することがあります。

## 2.5 設定のバックアップと復元

設定データにはメニューなどの項目が含まれ、初期化後に個人設定をすばやく復元できます。**チャンネル周波数／名前、校正データ、フォントデータは含まれません。**

### 使用例

1. ウェブページ「設定をバックアップ」エクスポート  
2. 需要时「設定を復元」写回  

### 設定をバックアップ

1. 正常起動 → USB →「設定をバックアップ」→「設定データをエクスポート」  
2. 得到 `config_backup.dat`（512 字节）  

**技術：** SPI 物理アドレス `0x00A000` から、サイズは 512 字节（`0x200`）；ブロック単位で読み取ります。

### 設定を復元

1. 正常起動 →「設定を復元」→ バックアップファイルを選択 → 書き込み → 自動再起動

## 2.6 SPI Flash の保存アドレスマップ

ユーザーデータは主に **PY25Q16 SPI Flash（2 MB，`0x000000`–`0x1FFFFF`）**。MCU 片内 Flash（`0x08002800` 起）にはプログラムのみが格納されます。

ウェブの周波数書き込み機能とファームウェアは、主に **SPI 物理アドレス**；旧ツールの **EEPROM 逻辑アドレス** 由 `eeprom_compat` によって SPI にマッピングされます。

### 記憶媒体の概要

| 介质 | アドレス範囲 | 容量 | 用途 |

| MCU 片内 Flash | `0x08002800` – `0x0801FFFF` | 118 KB | ファームウェア（Bootloader 在 `0x08000000`） |

## 2.8 ファームウェア書き込みに関する FAQ

（FAQ 全体は第3章を参照してください。ここでは書き込み関連の質問を抜粋します。）

1. **書き込み直後に英語で表示される？**  
   対応するフォントデータを書き込み、 **显示 → 显示言語** で中国語を選択してください。

2. **变砖？**  
   本機用ではないファームウェアを書き込んだり、別の周波数書き込み／校正変更ツールを使用したりしていませんか？アドレス構成はファームウェアごとに異なり、書き込みソフトは共通ではありません。必ず本サイトの手順に従ってください。

3. **他の人は正常なのに、一部の文字が表示されない？**  
   フォントデータとファームウェアのバージョンが一致していないか、ブラウザーに古いフォントファイルがキャッシュされています。キャッシュを削除して再度書き込んでください。

4. **純正ファームウェアに戻す際にパスワードを求められる？**  
   メニュー **「その他」→「復元出厂」→「原厂」(OEM)** → 確定 → 见「请電源オフ」后電源オフ → 用公式 CPS 刷原厂ファームウェア。この項目は AES 周波数書き込みキーを含む領域を消去し、CPS がパスワードを要求するのを防ぎます。詳細はウェブサイトの緊急ツールボックスにある同名の説明を参照してください。必要に応じて WeChat グループで相談してください（ウェブサイト右側のフローティング入口）。

5. **画面にノイズが出る／電池残量が乱れる／電圧が不正確？**  
   校正異常です。純正の校正データを復元してください。バックアップがない場合は、ウェブページで提供される純正校正データを使用できます。

# 第3章 よくある質問とその他

## 3.1 よくある質問

1. **「チャンネル」→「出力」里显示「用 xxx」とはどういう意味ですか？**  
   回答：ユーザーが **「その他」→「设置出力」** でカスタマイズした出力レベルがここに表示されています。

2. **刚刷入ファームウェア显示英文？**  
   答：対応するフォントデータを書き込み、 **显示（display） → 显示言語（lang）** で中国語を選択してください。

3. **デュアルチャンネル時、下側にチャンネル名が表示されたり周波数が表示されたりするのはなぜ？**  
   回答：仕様です。チャンネル名に漢字が含まれない場合、下側に周波数、左上にチャンネル名が表示されます。チャンネル名は最大約5文字の漢字（英字約15文字）です。表示可能な長さを超えるとスクロール表示になります。ウェブで周波数を書き込む際、漢字が5文字を超えると表示は...

4. **变砖了？**  
   答：本機に適合しないファームウェアを書き込んでいませんか？別の周波数書き込みツールを使ったり、校正値を変更したりしていませんか？ウェブページの手順どおりに書き込みましたか？  
   > ファームウェアによってメモリアドレスの使い方が異なるため、周波数書き込みソフトは共通ではありません。未検証のソフトを使用して文鎮化した場合は自己責任となります。

5. **别人フォントデータ正常，我缺某些字？**  
   答：フォントデータ与ファームウェア版本不一致，或浏览器缓存旧文件。清理缓存后重刷匹配版本。

6. **ラジオの周波数帯が合わない？**  
   答：ラジオ画面で **`1` / 長押し `1` / `F+1`** を使って国・地域の周波数帯を切り替えてください。詳細は [1.2](#12-ラジオの起動と使い方)。

7. **本体は K1 なのに、システム情報には K5 と表示される？**  
   答：ユーザー設定によるものです。 **PTT** と、そのすぐ下のサイドキーを同時に押しながら起動すると、関連設定を解除できます。バッテリー種類は対応機種を選択してください。画面には通常 K1 または K5 のみが表示されます（K5/K6 は同じチップで、外装が異なります）。

8. **トーンなどを変更しても、チャンネル切り替えや再起動で元に戻る？**  
   答：**メモリーチャンネルモード下変更参数后，必须再执行「存チャンネル」**，否则只是临时更改。详见 [1.4](#14-チャンネルの保存方法)。

9. **# を長押ししてキーロックすると PTT までロックされる？**  
   答：**「その他」→「锁键範囲」** キーボードのみ、または PTT も含めてロックする設定を選べます。

10. **純正ファームウェアに戻す際にパスワードを求められる？**  
    答：用 **「その他」→「復元出厂」→「原厂」(OEM)**，確定后见「请電源オフ」再電源オフ，用公式 CPS 刷原厂。详见ウェブサイト应急工具箱教程。建议加微信群（ウェブサイト右侧悬浮）。

11. **雪花屏 / 电量飘忽 / 電圧不对？**  
    答：校正问题，復元原厂校正；未バックアップ可用ウェブページ原厂校正。

12. **ラジオ使用中にアマチュア無線の信号が入ると、ラジオが中断・終了する場合としない場合があるのはなぜ？**  
    答：デュアル待受下仅当**メインチャンネル**有信号才打断終了ラジオ。BK4819 は真のデュアル待受に対応しておらず、順次切り替えて監視します。ラジオモードで常に監視を続けると、受信品質が低下し、消費電力も増えます。

13. **電池の消耗が激しく見え、残量が目に見えて変化するのはなぜ？**  
    答：送受信時の電流変化によって電圧表示が変動します。古い電動バイクでアクセルを回すと残量表示が急に下がるのと似ており、正常な現象です。一部の他のファームウェアでは送信中に残量を更新しないため、より「安定」して見えます。

14. **全周波数帯のロック解除ではどの範囲を使えますか？ハードウェアの制限はありますか？**  
    答：受 **BK4819** 限制：Band1 约 18–630 MHz，Band2 约 84–1300 MHz；**630–840 MHz 为硬件死区**，ファームウェア无法绕过。

    **全解除（全部解锁／F_LOCK_NONE）のおおよその使用可能範囲：**

    | モード | 受信（RX） | 送信（TX） |
    |------|-----------|-----------|
    | 標準モード | 50 MHz ~ 600 MHz | 50 MHz ~ 600 MHz |
    | 広帯域受信モード | 18 MHz ~ 1300 MHz（排除死区） | 18 MHz ~ 600 MHz + 470 MHz ~ 1300 MHz |

    **メニュー「周波数帯ロック」の主な選択肢（現在のファームウェアに対応。コンパイル設定項目を含む）：**

    | モード | 説明（送信関連） |
    |------|------------------|
    | デフォルト | 137–174 / 400–470 |
    | FCC 业余 | 144–148 / 420–450 |
    | CA 业余 | 144–148 / 430–450（コンパイル時に有効化されている場合） |
    | CE 业余 | 144–146 / 430–440 |
    | GB 业余 | 144–148 / 430–440 |
    | 137–174 / 400–430 | 分区表 |
    | 137–174 / 400–438 | 分区表 |
    | PMR 446 | コンパイル時に有効化されている場合 |
    | GMRS/FRS/MURS | コンパイル時に有効化されている場合 |
    | 全部禁用 | 禁发 |
    | 全部解锁 | メニューで約 **10 次** 才激活（防误触） |

    **その他：**

    - 约 280 MHz 为 VHF/UHF 分界，フィルターとパワーアンプの利得に影響します  
    - 広帯域受信では短波から1.3 GHzまで受信できますが、送信は周波数帯設定の制限を受けます  
15. **本体の左右キーまたは上下キーの動作が逆なのはなぜ？**  
   答：ファームウェアは K1 と K6 V3 に対応しているため、手動で設定する必要があります。可同时按住 **PTT** 与下方紧挨侧键起動以解锁相关选项；ナビゲーションキーで対応機種を選択してください。画面通常只显示 K1 或 K5（K5/K6 本质同芯，外壳不同）。
